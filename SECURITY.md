# Security Policy

## Scope

This repository is IDE configuration: plugin lists, a keymap, a file template and Toolbox
settings. It contains no application code and no service. In scope:

- A plugin id in `plugins/` that points at a different or malicious plugin
- A setting or file that leaks a credential or a licence key
- Setup instructions that would leave insecure file permissions behind

## Out of scope

- A plugin listed here having a vulnerability of its own, report that to the plugin's author
- A pinned plugin version being out of date

## Reporting a vulnerability

> [!IMPORTANT]
> Report privately, not in a public issue. Email contact@isaacadjei.me with details and
> reproduction steps. Expect an acknowledgement within a few days.
